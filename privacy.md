# Privacy policy

This page says what happens to information about visitors of this website. Last updated: 15 November 2026.

## Who is responsible

The site is run by Raphael Bucher, Horw, Switzerland. Questions about privacy can be sent to [contact@raphaelbucher.ch](mailto:contact@raphaelbucher.ch).

## Cookies, analytics, and tracking

This site does not use analytics or other tracking, and it does not set cookies.

Styles, scripts, and fonts are files on this site. They are not loaded from an analytics service or a public content network.

## Hosting

The pages are static files.

The site at [raphaelbucher.ch](https://raphaelbucher.ch) is delivered by a web server. That server may store a visitor's IP address in its connection logs, together with the time of the request and the page that was requested. Those logs are not used to build a profile of visitors.

The same pages are also published with GitHub Pages. GitHub may process visitor IP addresses in its server logs. That is described in the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).

## Comments and share links

A blog post loads comments from [utterances](https://utteranc.es). That service reads and stores comments as issues in the GitHub repository for this site, so GitHub processes them under the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement). Signing in to comment is done by GitHub.

The share buttons do not contact Facebook, X, or LinkedIn on their own. Using one opens that site and sends it the address of the page.

## Your rights

The Swiss Federal Act on Data Protection (FADP, also called revDSG) and, where it applies, the EU General Data Protection Regulation (GDPR) give you rights over personal data about you. You can ask for access to that data, for it to be corrected or deleted, and for processing to be restricted or stopped. Where the GDPR applies, you can also ask for a portable copy. You can lodge a complaint with the [Swiss Federal Data Protection and Information Commissioner](https://www.edoeb.admin.ch/en) or with a European data protection authority.

This site does not keep user accounts. The personal data that can be tied to a visit is what the web server or GitHub stores in logs, and what GitHub stores if you comment.
